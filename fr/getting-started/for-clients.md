# 🤝 Pour les clients : votre plateforme, en ligne en quelques heures

Une plateforme d'apprentissage complète, prête pour la production, déployée dans **votre** compte AWS. La plateforme est en ligne en quelques heures ; le déploiement entreprise complet (branding, contenu, formation) s'achève en 3 semaines grâce à un playbook de livraison éprouvé. Vous maîtrisez tout une fois notre mission terminée.

{% hint style="success" %}
**L'essentiel :** une plateforme d'apprentissage moderne, à votre image, sur une infrastructure que vous contrôlez, pour un coût comparable à quelques licences SaaS LMS, sans aucun frais de licence par utilisateur, pour toujours.
{% endhint %}

## ✅ Le package

| Livrable | Ce que cela signifie pour vous |
|---|---|
| 🎓 **Plateforme complète** | Application apprenant, console d'administration, moteur de cours, à votre identité |
| 🏗️ **Infrastructure as code** | Votre stack AWS entière en Terraform, révisable et auditable par votre équipe IT |
| 📖 **Documentation** | Ce site : architecture, runbooks, guides d'exploitation |
| 🎓 **Transfert de compétences** | Votre équipe apprend la plateforme pendant le déploiement, pas après |
| 🔒 **Baseline sécurité** | Durcie après un audit indépendant complet (août 2026) |

## 📅 Le calendrier des 3 semaines

| Semaine | Focus | Vous voyez |
|---|---|---|
| **1** | 🏗️ Infrastructure | Votre environnement AWS se déploie : réseau, bases de données, CDN, sécurité |
| **2** | 🔌 Plateforme + intégrations | La connexion fonctionne, les cours se chargent, le chat et la vidéo sont connectés, les e-mails partent |
| **3** | 🚀 Contenu + mise en production | Votre contenu migré, votre équipe formée, bascule DNS, validation finale |

{% hint style="info" %}
**Pourquoi 3 semaines est réaliste :** ce playbook a déjà été exécuté. Les modules Terraform, les scripts de déploiement et la checklist de validation existent déjà, nous les configurons pour vous, nous ne les inventons pas.
{% endhint %}

## 📋 Ce dont nous avons besoin de vous

Pour respecter le calendrier, quatre éléments (détaillés dans les [Prérequis client](../../deployment/client-prerequisites.md)) :

1. **☁️ Un sous-compte AWS dédié**, isole le projet, simplifie la facturation, vous gardez le contrôle total
2. **🌐 Délégation DNS**, un sous-domaine comme `learn.yourcompany.com`
3. **🎨 Assets de marque**, logos, couleurs, typographie
4. **👤 Contacts désignés**, IT, sécurité et un sponsor projet

| Poste | Coût |
|---|---|
| ☁️ Infrastructure AWS (pilote : 100 à 1 000 apprenants actifs) | **225 à 300 $/mois**, sur votre propre facture AWS |

{% endhint %}

## 🆘 Options de support disponibles

| Service | Engagement |
|---|---|
| ⚡ Réponse aux incidents plateforme (GTI) | Intervention **24 h max** sur les problèmes côté plateforme |
| 🎧 Support technique apprenant | Réponse **2 h max** sur les problèmes d'accès, de navigation et d'utilisation |
| 🚑 Fallback en cas d'incident bloquant | Une plateforme neuve peut être **redéployée en moins de 3 h** pour que les apprenants gardent l'accès pendant la résolution de l'incident |
| 🎫 Gestion des incidents | Suivi par tickets, chaque demande est enregistrée, priorisée (basse/moyenne/haute) et suivie jusqu'à clôture |
| 👥 Équipe dédiée | Support technique, support pédagogique et un chef de projet digital, joignables 5 jours sur 7 par téléphone, chat ou e-mail |

{% hint style="info" %}
💡 **Le support est structuré, pas ad hoc.** Les tickets, les priorités et un contact projet désigné garantissent que rien ne tombe entre les mailles du filet, et vous recevez un rapport d'activité régulier sur les demandes et leurs résolutions.
{% endhint %}
